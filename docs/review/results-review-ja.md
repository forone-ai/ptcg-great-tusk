# 「不完全情報ゲームの完全情報ゲーム化」を支える検証結果

テーマを維持したまま、追加情報の平均的な利益を測った結果をレポートへ加えられます。主検証では、事前に定めた300対戦の全局面を解析できました。隠れた配置を追加して知る選択方法の利益は平均0.80ポイントでした。片側95%上限は1.16ポイントで、事前の許容差5ポイントを下回りました。

この結果は「差が有意でなかった」という結論ではありません。両側95%区間は0.43〜1.22ポイントで、追加情報には小さい正の利益が残っています。固定した配置モデル・候補・継続方策の下で、その平均的な利益が小さいことを示した結果です。真の完全情報最適解と同等であると証明したものではありません。

## 主検証の数字

| 指標 | 結果 |
|---|---:|
| あらかじめ選んだ独立した元対戦 | 300対戦 |
| 解析できた予定局面 | 300/300局面 |
| 終局まで計算した継続 | 925,696本 |
| 主検証の例外・打切り | 0本 |
| 配置を追加して知る選択の平均利益 | 0.80ポイント |
| 両側95%区間 | 0.43〜1.22ポイント |
| 事前に判定へ使うと決めた片側95%上限 | 1.16ポイント |
| 事前の許容差 | 5ポイント |
| 同点を考慮した参照選択の安定性 | 98.3% |
| 正の差だけを使った補助評価の上限 | 4.29ポイント |

得点は勝ち1、引き分け0.5、負け0です。上の「ポイント」は得点差を100倍した値です。各局面の多数の配置・行動・反復を、別々の独立対戦として数えていません。補助上限4.29ポイントも、今回の有限計算の差に関する値です。

## 数字と一緒に示すべき内訳

300局面のうち、試したすべての行動・継続で勝った局面は183、すべて負けた局面は22、結果が変わった局面は95でした。これらは有限回の計算で観測した分類であり、強制勝ち・強制負けの証明ではありません。

同率の最良行動が多いため、安定性98.3%だけを根拠に参照が最適に近いとは言えません。平均の差が小さくても、個別には配置情報から大きな利益を得る局面がありました。本文は「全局面で情報が不要」ではなく、「指定した条件で平均的な追加利益が小さい」とします。

## 実戦でどの程度起きていたか

最終提出2件の2,000対戦のうち、1,999対戦のリプレイを確認しました。相手の山札・手札・残りサイドの合計が15枚未満になる局面へ到達したのは776/1,999対戦（38.8%）です。最終的に勝った対戦が602、負けた対戦が174含まれます。

自分の第5ターンのMAIN判断までに終了した107対戦のうち、97対戦は負けでした。序盤を耐えて狙った局面に到達することが、まだ改善すべき点です。途中で終了した対戦を「非公開情報がゼロになった成功例」として数えていません。

## 原稿を強くする変更

「不完全情報ゲームの完全情報ゲーム化」を、戦略の着想、実戦での到達、局面での判断への影響という順に説明します。元のテーマを一般的な勝率改善へ置き換えず、具体例・到達頻度・固定標本の主検証で支えます。

実装の説明も修正します。三つの時計は診断値であり、行動選択に直接使われる式ではありません。実際の山札消費の制限、対面ごとのルート、行動の順序を具体例で説明します。Battle Cageの防御範囲、Rock Fighting Energyのタイプ条件、Crushing Hammerが2枚である点もそろえます。

最終提出は対戦相手の登録一覧を同梱できず、探索が動いていませんでした。公式成績799.3と、今回の提出後の検証は区別します。今回の結果で公式成績が改善したとは書きません。

## 残る限界

両方の比較方法に正しい60枚のデッキ構成を与えています。相手は実際のKaggleエージェントではなく、登録済みの代理方策です。配置の生成も、全履歴にわたる厳密な推定ではありません。自分の山札順と未確定サイドも配置に含めているため、相手の非公開枚数だけが差を引き起こしたとは言えません。

このデッキや方策が、判断に必要な情報の少ない局面をどれだけ増やしたかという因果効果は未確認です。より強い相手・継続方策でも同じか、条件を作る方策が実戦の勝率を上げるかは次の検証です。今回の成果は賞金獲得の保証ではありませんが、着想だけだった部分に、条件を明示した実測と再現資料を加えられます。
