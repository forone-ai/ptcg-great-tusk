# 探索的な説明例と反例（固定した主検証300局面の事後分析）

主検証の母集団・統計は変更していない。以下は説明目的で選んだ例であり、頻度の推定や事前登録した検定結果ではない。

全300局面を検査した結果、厳密な同点込み共通bestと手間の差がある局面は62件。即時終局の共通手がある局面を除くと55件。各分割で世界全体のbest集合の共通部分が空となる反例は27件。

共通例は全世界・全32回/偶数16回/奇数16回・共通集合外の全手に対する最小平均優位を降順で並べ、次に最も劣る比較手への最小優位、最後にIDで決めた。反例は同じ分割で共通部分が空であることを条件に、プールした標本のoracle gap順で選んだ。これらの選択後の差は信頼下限ではない。
