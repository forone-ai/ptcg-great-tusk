## 改善案A: エネ供給の寿命設計 (ep93734849 オーロンゲ戦の敗着系統)

**事象**: エネ12枚(草6/ロック4/ミスト2)がT9で手札から尽き、装着がT17まで途絶。
攻撃が止まり(シザー3連でサイド3枚まで取った良い流れが失速)、取り切り速度負け。

**設計案**:
1. **エネ在庫会計**: 「場の装着済み+手札+山の残エネ」を毎ターン集計し、
   『残りの攻撃予定ターン数×1枚』に足りるかを判定する関数(dig_lifetime_okのエネ版)。
2. 不足予測時、wantsのエネ需要を段階的に引き上げ(既存の「在庫4未満」条件は
   ハンマー対面限定 → 攻撃継続中の全対面に拡張)。
3. **夜のタンカのエネ回収を明示**: タンカはトラッシュから基本エネを拾える。
   エネ枯れ局面での役割(体でなくエネ)を条件分岐する。既存採点はポケモン優先の疑い。
4. 探検家/むしとりの選択でも、在庫警報中はエネを体より優先。

**検定**: オーロンゲ面+ミラー+ルカリオ(長期戦系)でA/B。エネ装着率(装着ターン/全ターン)を
テレメトリに追加して回帰を数値で見る。

## 改善案B(診断訂正済み): 対フーディンの立ち上がり速度+ハンマー戦争 (本番0勝4敗の主因)

**訂正(2026-08-17 06:20)**: 当初「T11装着パス=順序バグ」と診断したが誤り。
_PENDING_ATTACH精査の結果、T11は貼れる正当な先が無かった(キバ2エネ上限/壁は対非ex禁止)
=ルールは正しい。真因は本番4連敗(ep93735761/93738471/93741190+§15)に共通する
**①2号機キバ・特殊エネの立ち上がりが相手の賞ペース(2T/枚)より1〜3ターン遅い
②相手の改造ハンマー3枚がミスト/ロックの免疫を剥がす(ハンマー戦争)**。

**調査手順(修正より先)**:
1. T11局面をリプレイからシーンテスト化(手札/盤面を固定)して再現。
2. ルール採点値をダンプ: リーリエのplay_scoreと装着optionのattach_scoreの実数比較。
3. 探索上書き(ovr)テレメトリの確認 — ルールは装着を選んだのに探索が
   リーリエへ上書きした可能性。
4. コード上の既存機構 `_PENDING_ATTACH`(rule_policy L4147近辺)が
   このケースで働かなかった理由の特定。v15a教え「装着→リーリエ順序」の適用範囲確認。

**仮修正案(調査結果待ち)**: MAIN選択で「装着が合法×手札にエネ×未装着」の間、
手札を山に戻す系サポート(リーリエ)の点数に先行ガードを置く。ただし
「エネを貼らずに回すのが正しい局面」(貼り先が全部捨て駒等)の例外を残す。

**検定**: フーディン面(53.5%)でA/B。この1手の頻度は高くないので、
装着率テレメトリ+シーンテストで挙動保証し、面勝率は参考値扱い。
