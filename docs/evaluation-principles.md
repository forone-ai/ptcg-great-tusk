## 中心式のPTCG翻訳

観測スコア(レート) = **Q(真の実力)** + δ(メタ変動) + ε(サンプル誤差) + b_fb(ベンチ/LB過適応) + b_proto(計測の漏れ)

| 項 | うちでの実例 | 対策(実装済み/採用) |
|---|---|---|
| Q | 収束レート(v28j=786)とメタ加重ベンチ | **最終判断はQの推定のみで行う** |
| δ メタ変動 | 8/10の1044と最終週の750は別市場 | ピークを実力と呼ばない(メモリ記録済み) |
| ε | 新規提出の±100振動(10-20戦) | 25戦未満で判断しない |
| b_fb | 10面均等ベンチでユキノオー+13を「改善」と誤認(本番遭遇1%) | **メタ加重ゲート**: 面ごとの勝率×本番遭遇率で合算 |
| b_proto | SlotNet v1の分布ズレ / 7月のプロキシデッキ誤読 | 分布一致の検証をゲート前に必須化 |

## チェックリスト7項目のPTCG版

1. **Qの定義**: 「締切時アクティブ2機の締切後収束レート」。それ以外は全て代理指標。
2. **識別可能な信号を選ぶ**: 遭遇率×改善幅で投資先を選ぶ(オーロンゲ43%>>りんご2%)。
   LO戦略自体が「予測可能な現象(山切れの決定論時計)を選ぶ」設計であり、これは強み。
3. **共通成分の除去**: A/Bは同面・同ラウンド対で比較(相手プール雑音の中和)。実施済み。
4. **集計単位**: 面別勝率+メタ加重合算。均等平均は廃止。
5. **支配性排除**: 2R合算・面n=1024固定。1面の異常が合計を支配しない構造。
6. **漏れの特定**: ベンチは既知相手= identifyが有利に働く(beliefの未知+3.5が見えない)。
   既知/未知の分計を常に添える。
7. **優劣の不確実性**: z値でなく**ブートストラップ順位保存確率** P(候補>対照) を報告する。
